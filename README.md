annual_out.csv is an aggregated data file upon which most of the anlysis rests. It is an outcome file from the original data files data.js and data_v6.json from State Information System Authority. 
Both files are available as machine-readable X-Road factsheet data files at 
https://x-tee.ee/factsheets/EE/js/data.js (2003–2018) and 
https://x-tee.ee/factsheets/EE/js/data_v6.json (2016 onward).
Scalar_analysis.R is the main R-script used for data preparation, analysis, figure generation, modeling and diagnostics.
